낚시의 기술 — 전시 시작

간단한 방법 (터미널 없이)

  1. Chrome에서 eecchaann.github.io/waysofhooking/show 열기
  2. 카메라 권한 허용 (처음 한 번만)
  3. 화면을 더블클릭 → 전체화면 + 소리 켜짐

완전 자동 (메뉴바 없이, 클릭 없이 소리)

  1. 아래 버튼을 눌러 명령어 복사
  2. Spotlight(⌘+Space)에서 "터미널" 열기 → ⌘+V → Enter
  3. 끌 때는 ⌘+Q
